Core Endpoints

ZDB commands are highly extensible and modular. Example usage of the Backend class:

python 
from zdb.backend import ZDBBackend

backend = ZDBBackend()

# Fetch connected devices
devices = await backend.get_adb_devices()

# Flash a logical partition
await backend.fastboot_flash("system", "~/zdb_rom/system.img")

# Create a logical partition
await backend.fastboot_create_logical_partition("my_part", 1024000)
